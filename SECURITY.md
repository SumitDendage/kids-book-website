# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Email **learnwithwhy6@gmail.com** with:

- what you found and where (page, API route or file),
- the steps to reproduce it,
- what an attacker could do with it.

You will get a reply as soon as the report has been read. Please give the project reasonable time to fix the problem before you share details publicly, and do not access other people's accounts or data while testing.

## Scope

- The website at [www.learnwithwhy.com](https://www.learnwithwhy.com) and the code in this repository.
- The `api` Edge Function and the database rules in [`supabase/`](supabase).

Out of scope: screenshots or photos of worksheets (no website can prevent them; the watermark identifies the buyer), and reports that need physical access to a user's device.

## How the project protects users

The security design is described in [supabase/docs/SECURITY.md](supabase/docs/SECURITY.md) and summarised in the [README](README.md#security).
